Detailed Description

Main manager class for the DCM (Dynamic Constraint Manager) system.

Provides unified CRUD operations for geometric figures and requirements. Manages connected components of the constraint graph.

Change geometry through addFigure / removeFigure / update*; inspect it via getStorage(). Mutable storage() is an escape hatch only; the caller bears all consequences (see that method’s docs).

◆ solveWithTargets()

TargetSolveResult OurPaintDCM::DCMManager::solveWithTargets ( std::span< const PointTarget > targets,
TargetPolicy policy = TargetPolicy::Require,
double residualTolerance = 1e-6 )

Solve globally with point positions held temporarily for this call.

Targets address whole coincidence groups. Identical targets for a group are accepted; different targets for the same group are invalid. Existing Fix requirements always take precedence. Require fails when a target cannot be retained. Prefer may release targets and retry from the prepared geometry. No requirements are created, and the previous solve mode is restored.

Failed calls and exceptions restore all pre-call coordinates. Result flags describe an accepted solution; usedFallback also records target relaxation when the final solve fails. Empty targets perform an ordinary global solve.

Exceptions
std::invalid_argumentfor invalid policy, tolerance, or targets.
std::runtime_errorif a target point does not exist.

Warning
