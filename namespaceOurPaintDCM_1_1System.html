std::optional< ConstraintDecomposition > OurPaintDCM::System::buildConstraintDecomposition ( const RequirementSystem & system,
ArticulationDecomposition decomposition )
nodiscard

Bind a local graph decomposition to its original requirement system. Each requirement and function has one owner. Empty blocks retain topological connections. nullopt requests ordinary solving when separation is unsafe or fewer than two blocks have functions. The plan stores no numerical values or function copies. Rebuild it when the system's function list, point aliases or geometry structure change; numerical success still requires residual validation.

◆ decomposeByArticulationPoints()

ArticulationDecomposition OurPaintDCM::System::decomposeByArticulationPoints ( const Figures::ObjectGraph & graph)
nodiscard

Decompose a supplied local graph into vertex-biconnected blocks. Bridges form two-vertex blocks; isolated vertices form singleton blocks. Self-loops do not affect decomposition. Shared vertices occur in each incident block. IDs within blocks, blocks and articulation points are sorted for reproducibility, not for numerical solving. Geometry and constraint functions are not copied.
