Detailed Description

NURBS with an expanded knot vector (including repeated knots). Non-periodic: N control points, N + degree + 1 knots. Periodic: N controls without a duplicated cyclic tail, N + 2*degree + 1 knots; controls repeat cyclically and knots[i + N] = knots[i] + period.
